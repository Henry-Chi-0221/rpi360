Your iPad is the viewfinder.

This page comes directly from your Raspberry Pi. Connect both devices to the same trusted Wi-Fi network, or use the configured Tailscale connection. No Mac, app account or pairing code is needed.

First visit: trust your camera

Safari needs a trusted HTTPS connection for the GPU preview. This is a one-time setup for this Pi, not a code you enter every time.

  1. Download Pi certificate
    Allow the configuration profile download.
  2. Open Settings → General → VPN & Device Management. Select the downloaded RPI360 camera certificate and tap Install.
  3. Open Settings → General → About → Certificate Trust Settings. Turn on full trust for RPI360 camera.
